Local AI tools, Claude Code skills, and slash commands. Each asset is small, self-contained, and works without a build step.

Install Browse the catalogue GitHub

Install

Tools first, then the Claude Code skills and commands. Re-run the same command to update. 

curl -fsSL https://raw.githubusercontent.com/yakovkhalinsky/ai-things/main/install.sh | sh
  • ol and model-bench → ~/bin
  • code-smells and comfyui-prompt → ~/.claude/skills and ~/.claude/commands
  • the checkout → ~/.local/share/ai-things

Restart Claude Code after installing so it picks up the user-level skills. Skip either half with AI_THINGS_INSTALL_TOOLS=0 or AI_THINGS_INSTALL_SKILLS=0; pin a ref with AI_THINGS_REF=<commit>.

Prefer a checkout? git clone … && ./scripts/install.sh installs the same skills into the current project's .claude/ instead.
