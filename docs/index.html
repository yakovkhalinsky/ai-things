Browse the catalogue View on GitHub

Use it

Clone once, then install the skills and commands into Claude Code. 

git clone https://github.com/yakovkhalinsky/ai-things.git
cd ai-things
./scripts/install.sh

The script copies the skills and commands into .claude/; restart Claude Code afterwards. On systems where the committed symlinks already work, this step is unnecessary. Tools install independently — see their pages.
